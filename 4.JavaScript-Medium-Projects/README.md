# 🚀 JavaScript Medium-Level Projects Showcase

> A curated collection of **medium-level JavaScript projects** built using **Vanilla JavaScript**, focusing on **DOM manipulation, real-world logic, UI interactions, and clean architecture**.  
> These projects are designed to strengthen **core JavaScript fundamentals** without relying on frameworks.

---

## 📌 Why This Repository?

This repository demonstrates:
- Strong understanding of **JavaScript core concepts**
- Hands-on experience with **DOM manipulation**
- Real-world features like **search, cart management, media controls**
- Clean, readable, and scalable code structure
- Project-based learning approach

If you want to master JavaScript **before jumping into frameworks**, this repo is for you.

---

## 🧠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6+)**
- **DOM API**
- **Browser APIs**

> ❌ No frameworks  
> ❌ No libraries  
> ✅ Pure JavaScript Power

## 📂 Projects Included

### 1️⃣ Pinterest-Style App (Dynamic Content + Search)

A Pinterest-inspired project that dynamically generates UI using JavaScript.

#### ✨ Features
- Dynamic **HTML generation using JavaScript**
- **DOM creation & manipulation**
- Real-time **search functionality**
- Data-driven UI rendering
- Clean separation of logic and UI

#### 🔧 Concepts Used
- `createElement`, `appendChild`
- Event delegation
- Search filtering logic
- Array methods (`map`, `filter`)
- Modular JS structure

---

### 2️⃣ Shopping Cart Functionality (Core E-Commerce Logic)

A fully functional cart system implemented using pure JavaScript.

#### ✨ Features
- Add items to cart
- Remove items from cart
- Increase / decrease quantity
- Auto price calculation
- Dynamic UI updates

#### 🔧 Concepts Used
- State management using JavaScript
- DOM updates based on state
- Event handling
- Conditional rendering
- Price calculation logic

---

### 3️⃣ Music Player 🎵

A custom-built music player using JavaScript and HTML5 Audio API.

#### ✨ Features
- Play / Pause music
- Next / Previous track
- Progress bar update
- Track duration handling
- Dynamic song info rendering

#### 🔧 Concepts Used
- HTML5 Audio API
- Event listeners (`timeupdate`, `ended`)
- DOM manipulation
- UI synchronization with audio state

---

### 4️⃣ Video Player 🎬

A custom video player created without any external libraries.

#### ✨ Features
- Play / Pause video
- Progress control
- Volume control
- Fullscreen support
- Custom UI controls

#### 🔧 Concepts Used
- HTML5 Video API
- Media events
- Custom controls logic
- DOM-based UI updates
